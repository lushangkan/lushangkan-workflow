# A/B 实验：输出规范对 GPT 的约束效果

## 摘要

同一个问题问 **GPT-5.6** 三次，分别注入不同规则，看输出差别。结论：**结构规则和用词规则都需要**，缺一不可。

| 文件 | 注入内容 | 字数 | 自造词 | 代码块 | 表格行 |
|---|---|---|---|---|---|
| `A-无规范.md` | 无 | 16859 | 23 | 56 | 23 |
| `C-仅用语规范.md` | 只给用词规则 | 13024 | 9 | 42 | 10 |
| `B-有规范.md` | 全套规则 | 9570 | 3 | 0 | 114 |

- **只给用词规则**（C）：句子变干净，但**结构病没治**，列表项比 A 还多
- **给全套规则**（B）：字数少 **43%**，自造词从 23 降到 3，映射全部改成表格
- `规则文本.md`：实验里注入的规则原文，也是 SKILL.md 的草稿
- `给Claude的实验输入.md`：给 Claude 跑同样实验的现成输入（Anthropic 通道当时不可用，未执行）

## 怎么复用

改规则后重跑同一个问题，和这三份基线对比。指标看上面那张表的四列。
